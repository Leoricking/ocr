OCR Engine v4.4.2 安裝說明
適用：Windows 10 / Python 3.12 / RTX 3060 / PaddleOCR 2.10.0
更新：GUI 改用獨立 worker process，原生 CUDA 崩潰不再關閉 GUI

============================================================
最短安裝流程
============================================================

1. 開啟 PowerShell，切換到 OCR 專案資料夾：

   cd "C:\Users\Rossi\Documents\Claude\OCR"

2. 執行一鍵安裝：

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\install_ocr_gpu.ps1"

3. 安裝完成後驗證：

   python -m pip check
   python -c "from paddleocr import PaddleOCR; print('PaddleOCR OK')"
   python -c "import paddle; paddle.set_device('gpu:0'); x=paddle.randn([1,3,64,64]); w=paddle.randn([8,3,3,3]); y=paddle.nn.functional.conv2d(x,w); print('GPU OK:', list(y.shape))"

4. 啟動（擇一）：

   GUI：  python .\ocr_gui.py    或雙擊 run_gui.bat
   CLI：  python .\ocr_engine.py 或雙擊 run_cli.bat

============================================================
Worker Process Safety（v4.4.2 新功能）
============================================================

GUI 從 v4.4.2 起使用獨立 subprocess 執行 PaddleOCR：

  ocr_gui.py ──Popen──▶ ocr_worker.py

優點：
- CUDA / Paddle 原生崩潰（access violation）不再關閉 GUI
- GUI 保持開啟，顯示 Windows 退出代碼說明
- 每頁寫入 checkpoint，支援斷點續跑
- GPU crash 自動重試，二次失敗自動改 CPU

Worker 日誌位置：
  logs\worker_<job_id>_YYYYMMDD.log
  logs\worker_crash_YYYYMMDD_HHMMSS.log

Checkpoint 位置：
  data\checkpoints\.ocr_state_<hash>.json

若 worker 卡住無回應（GUI 顯示「Worker 可能無回應」）：
  1. 按 GUI「全部取消」（等待 10 秒後自動 terminate/kill）
  2. 或手動：taskkill /PID <Worker PID> /F

CLI（python .\ocr_engine.py）仍使用原本的 in-process 穩定模式。
GUI 才使用 worker process isolation。
